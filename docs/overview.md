# ZScript Overview

## Purpose

This document provides a general overview of ZScript, how to create new script files and the syntax required to run them. This document does not detail the required installation procedure for ZScript, and assumes ZScript has already been installed correctly on your system.

## Creating a ZScript File

Creating a ZScript file is simple - just create a new text document and ensure the extension ends in '.z' so it will work seamlessly with ZScript. Once the file is created with the correct extension, you are free to start writing your scripts!

## Running a ZScript File

To run a ZScript file, simply type `zscript <filepath>` where `<filepath>` is the path to your script file!
