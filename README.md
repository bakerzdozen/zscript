# zscript


## About

ZScript is a scripting language created in C, to allow easy integration with a wide range of products from microcontrollers and embedded devices to servers and cloud infrastructure. Currently, it is in very early development with only basic features:

- **Optional semicolons**
- `while` loops
- `if`/`else if`/`else` statements
- `true`/`false` booleans
- `output()` function which outputs the given object to terminal
- `input()` function which returns input string from terminal
- `size()` function which returns the size of the given object
- `type()` function which returns a string of the given objects type
- Support for custom functions
- Support line comments with `\\`

While the project is still in its infancy, the best source of truth for the syntax and supported functions are the example script files found in the scripts folder.
